# CAPRIOLE

A streamlined first-person hop-and-bop roguelite: a wind-up clockwork goat ascends a
stack of procedurally generated floating-island spheres, flat-shaded the way a 1995
PlayStation dreamed. Double- and triple-jump (the camera pitches down at the apex so
you can see your landing), stomp from above, collect pods, draft caprices, fall upward.

Clean-room transposition of *Jumping Flash!* (PSX 1995) conventions into a roguelite.
All visuals code-generated (Three.js geometry, canvas textures — no image assets).
Score: House Band (code-composed WebAudio), register: bouncy toybox synth-funk.

- `DESIGN-SEED.md` — the founding contract (reference laws, milestones, stop line)
- `CLAUDE.md` — builder hard rules
- `docs/M0-STUDY.md` — clean-room study of the reference
- `PROGRESS.md` — dated build log + operator ratify-notes per run
- `dist/capriole.html` — the single-file build (boots from file://; regenerated by the build)

## Developing

Toolchain deps (three/esbuild/playwright) are dev-only; the shipped artifact is one file.

```
npm install                       # one-time: toolchain devDeps
npx playwright install chromium   # one-time: headless browser for probes
npm test                          # node --test — the WebGL-free sim suite
npm run build                     # -> dist/capriole.html (three inlined, boots file://)
npm run probe                     # headless render proof -> proofs/M0/*.png
```

Layout: `src/sim/*` is the deterministic, WebGL-free game sim (`node --test` targets it);
`src/render/*` + `src/main.js` are the renderer, bundled into the single file;
`src/engine/*` is shared kit (RNG, debuglog, House Band). `vendor/three/` is the
pinned, vendored Three.js (no CDN).
