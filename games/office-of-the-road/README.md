# THE OFFICE OF THE ROAD

A fully streamlined JRPG roguelite. The party marches itself — the player is the desk it
reports to. FF3-style swappable jobs (bureaucratic trades), a tarot deck played into
auto-resolving battles, mandates, quartermaster shops, and certifications that compound
across expeditions — under a Candide / Don Quixote / Kafka register.

- **Founding contract:** [DESIGN-SEED.md](DESIGN-SEED.md) (register laws, milestones,
  studio-sweep amendments). Builder hard rules: [CLAUDE.md](CLAUDE.md).
- **Play:** `npm run build` → `dist/office-of-the-road.html` boots from a file:// double-click.
- **Test:** `npm test` (node --test; deterministic, named RNG streams).
- **Art:** licensed packs (Willibab retro-FF collection, Simple 8-bit Sideview Battlers,
  GuttyKreum Pixel Tarot) — see [ATTRIBUTION.md](ATTRIBUTION.md) + materials/ASSET-MANIFEST.md.
- **Score:** House Band (code-composed WebAudio, chiptune/medieval register).
- **Register corpus:** design/register/ (PD Candide + Quixote-Ormsby + first-party Kafka
  translations; exemplars are reference, never game text).

Built by autonomous gauntlet runs on an always-on host; the orchestrator steers at run
boundaries; the operator reviews builds, not code. Status lives in PROGRESS.md and git log.
