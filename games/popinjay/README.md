# POPINJAY

## Hero
POPINJAY is a single-screen World's Fair sharpshooter: balloons travel on exact
periodic parabolas, the wire climbs straight up and persists as a wall, and a tour of
hand-tinted postcard stages turns each clear into a souvenir draft and each defeat
into a prize-counter scorecard. The build is a single offline HTML artifact, all art
is code-drawn, and the score is House Band WebAudio in the fairground ragtime/oompah
register.
