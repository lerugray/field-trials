# ATTRIBUTION — POPINJAY

POPINJAY ships with embedded OFL-licensed type and no image or audio asset packs. This
surface travels beside the single-file build so the font licences stay with the
artifact.

## Embedded fonts

### Rye

- Runtime family: `Popinjay Rye`
- Source file: `vendor/fonts/Rye-Regular.ttf`
- Licence text: `vendor/fonts/OFL-Rye.txt`
- Licence: SIL Open Font License 1.1

### Old Standard TT

- Runtime family: `Popinjay Old Standard`
- Source files:
  - `vendor/fonts/OldStandard-Regular.ttf`
  - `vendor/fonts/OldStandard-Bold.ttf`
- Licence text: `vendor/fonts/OFL-OldStandard.txt`
- Licence: SIL Open Font License 1.1

## Provenance note

All game visuals outside these fonts are code-generated at runtime. The score is
House Band WebAudio, composed in code; there are no shipped audio files.
