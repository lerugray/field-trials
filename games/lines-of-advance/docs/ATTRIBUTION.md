# Attribution

Lines of Advance implements game mechanics inspired by Guy Debord and Alice
Becker-Ho's *Le Jeu de la Guerre* (A Game of War). Under the idea-expression distinction, game rules and
mechanics as such are ideas/methods; all rules text, board art, code, and presentation in
this repository are original work. No text or artwork from any edition of the
book or board game is reproduced here, and this project is not affiliated with
or endorsed by the Debord estate.
