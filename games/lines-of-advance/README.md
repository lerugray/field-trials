# LINES OF ADVANCE

A modern strategy game of supply lines and massed attacks. Symmetric armies on a 25x20
board, deterministic combat, and an engine opponent that fights. Inspired by Guy
Debord's Kriegspiel: every unit projects lines of communication, and an army cut off
from its lines is an army about to die.

**Play it:** https://lerugray.github.io/field-trials/lines-of-advance/

## Run it

Open `index.html` for the source build, or build the single self-contained artifact:

```bash
npm run build
```

`node --test` runs the suite (156 tests). The release audit and its independent
re-run are documented in the lane reports at the repo root.
